# Le Petit Pain — Static Next.js Mockup

A French-first static Next.js sales mockup for Bakery Le Petit Pain in Hawkesbury, Ontario.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Build static files

```bash
npm run build
```

Because `next.config.mjs` uses `output: 'export'`, the finished static site is generated in the `out/` directory. Upload the contents of `out/` to any normal static host.

## Important

This is a concept mockup, not an official Le Petit Pain website. Verify business hours, menu items, branding, photos and all copy with the owner before publishing.
